= Architecture
:page-nav_order: 3
:page-has_children: true

P2Poolv2 is composed of two components: a Stratum server that miners
connect to, and a controller node that runs share accounting and talks
to the other nodes in the pool.

NOTE: Sample page, demonstrating a PlantUML component diagram.

[plantuml, components, svg]
.The two components of a node
....
@startuml
skinparam componentStyle rectangle

actor "Miner" as miner

node "P2Poolv2 node" {
  component "Stratum server" as stratum
  component "Controller node" as controller
  database "Share store" as store
}

cloud "Other P2Poolv2 nodes" as peers
component "bitcoind" as bitcoind

miner --> stratum : shares
stratum --> controller : shares
controller --> stratum : coinbase,\ndifficulty
controller --> store
controller <--> peers : share chain
bitcoind --> controller : block templates
@enduml
....

== Controller node responsibilities

. Accept shares from the stratum server.
. Tell the stratum server the current pool difficulty and coinbase.
. Run share accounting to decide which miners are paid how much.
. Validate shares received from peers.
. Talk to other nodes in the pool to coordinate payouts.
