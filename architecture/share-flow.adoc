== From miner to peers

[plantuml, share-sequence, svg]
....
@startuml
participant Miner
participant "Stratum server" as S
participant "Controller node" as C
participant Peers

Miner -> S : mining.submit
S -> S : check share difficulty
alt meets pool difficulty
  S -> C : share
  C -> C : validate and store
  C -> Peers : broadcast share
  S --> Miner : accepted
else below difficulty
  S --> Miner : rejected
end
@enduml
....

== Share lifecycle

[plantuml, share-states, svg]
....
@startuml
[*] --> Received
Received --> Validated : checks pass
Received --> Rejected : checks fail
Validated --> Confirmed : built upon
Confirmed --> Paid : block found
Rejected --> [*]
Paid --> [*]
@enduml
....

== Validating a share from a peer

[plantuml, validate-activity, svg]
....
@startuml
start
:Receive share from peer;
if (Parent known?) then (yes)
  :Check proof of work;
  if (Valid?) then (yes)
    :Store and relay;
  else (no)
    :Drop and penalise peer;
  endif
else (no)
  :Request parent;
endif
stop
@enduml
....
