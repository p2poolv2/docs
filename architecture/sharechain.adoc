== What Is a Sharechain?

A sharechain is a blockchain of shareblocks where each shareblock is a
has an embedded bitcoin header. The sharechain difficulty is much
lower than the bitcoin difficulty, and therefore we find it easier to
say that the sharechain is a blockchain of "weak" bitcoin blocks.

The bitcoin header includes the bits field for the target bitcoin
difficulty and the shareblock header includes a bits field capturing
the target sharechain difficuty. The diagram below shows the
relationship between a sharechain header and a bitcoin header.

[graphviz, shareblock-headers, svg]
.A shareblock's proof of work lives in its bitcoin header

  {rank=same; prevhash; prev}
  {rank=same; merkle; pow}

  prevhash -> prev [label="points to", constraint=false]
  merkle -> pow [ltail=cluster_bitcoin_header, constraint=false]

....

The sharechain is thus a chain of shareblocks, each referring to a
bitcoin block header that captures the proof of work. A shareblock can
embed the same bitcoin header as miners produce shares working on the
same bitcoin header.

[graphviz, sharechain-bitcoin-chain, svg]
.Shareblocks build on the bitcoin tip, and Shareblock 3 found Block 101

digraph sharechain {
  rankdir=LR
  newrank=true
  bgcolor="#0B0B0C"
  nodesep=1.4
  ranksep=0.45
  fontname="DejaVu Sans"
  fontcolor="#FFFFFFC7"
  node [shape=box, style=filled, fillcolor="#121212", color="#F7931A",
        fontname="DejaVu Sans", fontsize=12, fontcolor="#FFFFFF",
        width=1.3, height=0.45, fixedsize=true]
  edge [color="#F7931A", fontcolor="#FFFFFFC7", fontname="DejaVu Sans",
        fontsize=10, penwidth=1.2]

  subgraph cluster_sharechain {
    label="Sharechain"
    fontsize=12
    color="#FFFFFF66"
    s1 [label="Shareblock 1"]
    s2 [label="Shareblock 2"]
    s3 [label="Shareblock 3", fillcolor="#F7931A", fontcolor="#0B0B0C"]
    s4 [label="Shareblock 4"]
    s5 [label="Shareblock 5"]
    s6 [label="Shareblock 6"]
  }

  subgraph cluster_bitcoin {
    label="Bitcoin blockchain"
    labelloc=b
    fontsize=12
    color="#FFFFFF66"
    b100 [label="Block 100"]
    b101 [label="Block 101", fillcolor="#F7931A", fontcolor="#0B0B0C"]
    b102 [label="Block 102"]
  }

  // Each block points back to its parent.
  s1 -> s2 -> s3 -> s4 -> s5 -> s6 [dir=back]
  b100 -> b101 -> b102 [dir=back, minlen=2]

  {rank=same; s1; b100}
  {rank=same; s3; b101}
  {rank=same; s6; b102}

  // Previous bitcoin block hash in each shareblock's bitcoin header.
  edge [style=dashed, color="#FFFFFFC7", constraint=false]
  s1 -> b100 [xlabel="builds on    "]
  s2 -> b100
  s4 -> b101
  s5 -> b101
  s6 -> b102

  // Shareblock 3's bitcoin header met the bitcoin target and became
  // Block 101, which already links it to Block 100.
  s3 -> b101 [style=bold, color="#F7931A", penwidth=2,
              xlabel="found block:      \lheader met\lbitcoin target\l"]
}
