= Sharechain
:page-has_children: true
:page-nav_order: 24

A sharechain is a blockchain of shareblocks where each shareblock is a
has an embedded bitcoin header. The sharechain difficulty is much
lower than the bitcoin difficulty, and therefore we find it easier to
say that the sharechain is a blockchain of "weak" bitcoin blocks.

The bitcoin header includes the bits field for the target bitcoin
difficulty and the shareblock header includes a bits field capturing
the target sharechain difficulty. The diagram below shows the
relationship between a sharechain header and a bitcoin header.

== ShareBlock Header and Bitcoin Header

The relationship between the shareblock header and bitcoin header is
shown in the diagram below. Note that there are two `bits` fields,
capturing the two difficulty targets - one for the bitcoin block and
the other for the sharechain.

There are a number of other book keeping fields in the shareblock
header that we have not shown here. The important ones to note are the
previous block hashes, the bits fields and the time fields. The
bitcoin block header is shown in full.

== Sharechain and Bitcoin Blockchain

The sharechain is a chain of shareblocks. Each sharechain block embeds
a bitcoin block header that captures the proof of work. Th bitcoin
blockhash computed from the bitcoin header is compared to the
sharechain bits fields to validate the share meets sharechain
difficulty. The bitcoin blockhash is also compared to bitcoin header
bits field to check if this block is also a bitcoin block that can be
broadcast to the bitcoin network.

A number of shareblocks can be working on the same bitcoin previous
blockhash, as shown by dashed arrows in the diagram below. The orange
arrow from ShareBlock 3 to Block 101 shows that ShareBlock 3's PoW
meets the bitcoin difficulty and therefore Block 101 can be submitted
to bitcoin blockchain.

== Sharechain Provides Consensus on Payout Distribution

A sharechain provides Nakamoto consensus on the weak shares across all
nodes. With eventual consistency all nodes have the same view of the
sharechain and all nodes determine the same payout distribution when
building shares. This enables all nodes to validate all shares on the
sharechain payout honestly. Any share received from another peer that
does not distribute payouts as per the receiving node's local view is
rejected by the local node. See xref:pplns-accounting.adoc[PPLNS Share
Accounting] section to see how share accounting is handled in a
decentralized network.

Without this consensus provided by the sharechain, nodes can not
validate the payout distribution conforms to a receiving node's view
of the payout distribution. See the
xref:validation.adoc[Share Validation] section on how shares
are validated.

== Shares Have a Valuation

When the pool finds a block, all the shares within a certain depth
from the tip end up earning a payout from the bitcoin coinbase. This
depth depends on the length of the PPLNS (pay-per-last-n-shares)
window. Therefore, there is an intrinsic value that these shares
hold - they earn bitcoin when the pool finds a bitcoin block up to a
certain expiry time. This makes the shares behave as an Options
instrument with a known expiry.

Apart from the share's presence in the PPLNS window, there are other
fields in the shareblock that can be used to assign a value to the
shares.

. The pool difficulty the share was mined at - shareheader `bits`
. The bitcoin difficulty when the share was mined - bitcoi header `bits`
. The height of the share in the share chain

This value associated with a is what miners can sell too others. The
miners want an immediate payout and the buyers want to earn the
bitcoin that this share will earn when the pool finds a bitcoin block.

== Sharechain Provides UTXO & Script Based Transaction Support

The sharechain supports UTXO and Script based transaction
support. Each sharechain block has a coinbase paying the miner of the
share 1 share unit of the sharechain value. This captures the
intrinsic value of the share, and with the transaction support this
share can now be traded.

Using UTXO/Script the share can be traded for bitcoin using atomic
swaps, either on chain or off-chain. See the
xref:../payouts/marketplace.adoc[Sell Shares for Payouts] section on how such swaps
enable a payout mechanism for miners on P2Poolv2.
