= Spending UTXOs
:page-parent: Sharechain
:page-nav_order: 45

Spending a coinbase creates new UTXOs, and each later spend creates
more. The result is a chain of UTXOs rooted at the coinbase where the
coins were first created. The height of that root coinbase is called
the _root height_, and each descendant UTXO carries it. When a UTXO's
root height falls out of the PPLNS window, the UTXO can no longer be
spent. This rule limits every output to the lifetime of the proof of
work behind its root coinbase.

[graphviz, utxo-root-height, svg]
.Every output in a spending chain keeps the coinbase's root height
....

== Splitting Outputs

When a coinbase or a descendant is split into multiple outputs, each
output inherits the root height from the output it spends.

[graphviz, utxo-split, svg]
.Both outputs of a split keep the input's root height
....

  rankdir=LR
  bgcolor="#0B0B0C"

  input -> tx

== Merging Outputs

When multiple outputs are used as inputs to a transaction, every new
output inherits the lowest root height among the outputs being spent.
If a transaction spends outputs from two transactions, every new
output expires when the oldest root coinbase expires.

[graphviz, utxo-merge, svg]
.A merge gives every output the oldest input's root height
....
digraph merge_outputs {
  rankdir=LR
  bgcolor="#0B0B0C"
  nodesep=0.3
  ranksep=0.5
  fontname="DejaVu Sans"
  node [shape=box, style=filled, fillcolor="#121212", color="#F7931A",
        fontname="DejaVu Sans", fontsize=11, fontcolor="#FFFFFF",
        width=1.7, height=0.7, fixedsize=true]
  edge [color="#F7931A", fontcolor="#FFFFFFC7", fontname="DejaVu Sans",
        fontsize=10, penwidth=1.2]

  older [label="Output\nroot height 1,000", fillcolor="#F7931A",
         fontcolor="#0B0B0C"]
  newer [label="Output\nroot height 5,000"]
  tx [label="Transaction", shape=ellipse, width=1.3, height=0.5,
      color="#FFFFFF66"]
  outa [label="Output A\nroot height 1,000", fillcolor="#F7931A",
        fontcolor="#0B0B0C"]
  outb [label="Output B\nroot height 1,000", fillcolor="#F7931A",
        fontcolor="#0B0B0C"]

  older -> tx
  newer -> tx
  tx -> outa
  tx -> outb
}
....

Wallets and applications that split and merge outputs must therefore
choose inputs carefully, and should warn the user or ask for
confirmation before merging.
