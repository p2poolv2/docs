= Getting started
:page-nav_order: 2
:page-has_children: true

A P2Poolv2 node runs a Stratum v1 server for your miners and a p2p
network node that builds a share chain with in collaboration with
other p2poolv2 nodes. The share chain is a blockchain of weak bitcoin
blocks that supports blocks. See
xref:sharechain-design.adoc[Sharechain Design] for details on how the
share chain works.

The best place to see how to run a node is the
https://github.com/p2poolv2/p2poolv2/blob/main/README.adoc[README on
our repository].
