= P2Poolv2 Documentation
:page-nav_order: 1
:page-permalink: /
:page-description: Documentation for P2Poolv2, a permissionless, auditable, self-custodial Bitcoin mining pool.

[.fs-6.fw-300]
Permissionless mining pool where miners build block templates,
continuously audit accounting and are paid directly to their wallets
from bitcoin coinbase or by selling shares.
