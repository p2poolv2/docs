= P2Poolv2 Documentation
:page-nav_order: 1
:page-permalink: /
:page-description: Documentation for P2Poolv2, a permissionless, auditable, self-custodial Bitcoin mining pool.

[.fs-6.fw-300]
Mission: Replace pool operators with miners

P2Poolv2 is a permissionless mining pool where miners build block templates,
continuously audit accounting, and are paid directly to their wallets.

xref:getting_started.adoc[Get started,role="btn btn-primary fs-5 mb-4 mb-md-0 mr-2"]
https://github.com/p2poolv2/p2poolv2[View on GitHub,role="btn fs-5 mb-4 mb-md-0"]

== What Is Here

Run a node:: Run a node from source and connect your miners. See xref:getting_started.adoc[Getting started].

P2P Network:: How miners join a peer-to-peer network to reduce their variance. See xref:p2p-network-of-miners.adoc[P2P Network of Miners].

Sharechain:: The design of the sharechain, including how shares are validated and how PPLNS accounts for them. See xref:architecture/sharechain.adoc[Sharechain Design].

Payout Mechanisms:: How the pool pays miners without letting the coinbase size
limit its scalability. See how miners are paid directly xref:payouts/coinbase.adoc[from the bitcoin coinbase] and how small miners can xref:payouts/marketplace.adoc[sell shares for payouts].

Dashboards:: Dashboards that track the hashrate of the miners attached to a node and the global sharechain view. See xref:dashboards.adoc[Dashboards].
