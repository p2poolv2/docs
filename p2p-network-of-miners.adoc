= P2P Network of Miners
:page-nav_order: 20

P2Poolv2 is a peer to peer network where all peers in the network are
p2poolv2 mining nodes. Each node serves locally connected mining rigs,
so all nodes are responsible for one or more mining machines. The
nodes act as a gateway for the mining rigs to the peer to peer
network.

Each node runs the stratum protocol to distribute work to miner rigs
to collect work at 3 seconds interval from each node. This rapid
frequency allows us to estimate hashrate for each miner connected to a
node. However, not all these shares meet the difficulty of the
p2poolv2, which maintains a 10 second frequence for shares. We run
ASERT as the difficulty adjustment algorithm to aim for a 10s share
interval. See xref:architecture/stratum.adoc[Stratum Server & Vardiff] for details
on the difficulty adjustment algorithm used.

Shares that do meet the pool difficulty as determined by ASERT are
then gossipped over the peer to peer network. All receiving shares
validate the share. See xref:architecture/validation.adoc[Share Validation] for details.

The shares are thus replicated at all nodes and a Nakamoto consensus
is reached on the state of the sharechain. With this consensus all
nodes will agree on the state of the sharechain and how many shares
were mined by each miner at which difficulty. Using this, each node
can evaluate the rewards due to all miners when a share is
received. The share's bitcoin coinbase is thus verified that it meets
the expected reward distribution. See xref:architecture/pplns-accounting.adoc[PPLNS
Share Accounting] on how the accounting is always audited.
