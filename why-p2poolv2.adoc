= Why Do We Need P2Poolv2
:page-nav_order: 3


Bitcoin mining pools are a centralization pressure on bitcoin.

We need an open source software stack that participants can run to
pool their hashrate without a central operator that

. decides which transactions go into a block, or
. pays miners from its custodial wallet.

P2Poolv2 reboots the original P2Pool for bitcoin. It builds on the latest advances in bitcoin and uses modern programming languages and libraries, such as rust-bitcoin.

Given the https://mempool.space/graphs/mining/pools[pool distribution on mempool.space], the **goal of P2Poolv2 is to let miners mine blocks without depending on a centralized server** that a single organization controls.
